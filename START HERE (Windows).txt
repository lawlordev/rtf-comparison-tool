========================================================================
 RTF COMPARISON TOOL  -  START HERE (Windows)
========================================================================

WHAT IT DOES
  Compares two RTF files and reports how their CONTENT differs, ignoring
  cosmetic formatting (fonts, spacing, column widths). It tells you the
  files are EQUIVALENT, or lists every difference with its row/column.

WHAT YOU NEED
  - Windows 10 or 11
  - R already installed (from https://cran.r-project.org). Nothing else.
  - No administrator rights are required (see the note in Step 0).

------------------------------------------------------------------------
 STEP 0  -  UNZIP  (important - avoids the admin / "Run anyway" prompt)
------------------------------------------------------------------------
  Files that arrive by email or download are "blocked" by Windows, which
  is what triggers the "Windows protected your PC / Run anyway" message.
  You can clear that yourself, WITHOUT admin rights:

     1. Right-click the ZIP file  ->  Properties.
     2. At the bottom, tick  "Unblock".  ->  OK.
     3. NOW extract it: right-click the ZIP -> "Extract All..." -> Extract.

  Unblocking the ZIP first means the tool runs with no security prompt.
  Keep the whole extracted folder together; don't move files out of it.

------------------------------------------------------------------------
 STEP 1  -  ONE-TIME SETUP  (first time only; needs internet)
------------------------------------------------------------------------
  Open the "windows" folder and double-click:

        1-Install-Packages.bat

  A window opens and installs 5 small R packages. Wait for  SUCCESS ,
  then press any key to close. You only do this once per computer.

------------------------------------------------------------------------
 STEP 2  -  COMPARE TWO FILES  (by pasting their paths)
------------------------------------------------------------------------
  In the "windows" folder, double-click:

        2-Compare-RTF-Files.bat

  It asks for two file paths. For each one:
        - In File Explorer, hold SHIFT and right-click the RTF file
          -> "Copy as path"  (this copies the full path in quotes), then
        - click the tool's window and paste (right-click or Ctrl+V),
          and press Enter.

      File 1 (reference)  : <paste the first path>   [Enter]
      File 2 (comparison) : <paste the second path>  [Enter]

  Backslash paths and the surrounding quotes are both fine. The result
  appears immediately on screen:
        "EQUIVALENT"            = no content differences, or
        "N difference(s) found" = they differ (each one is listed)

  NOTHING is saved automatically. After showing the result it asks:

        Export report?  [t] TXT   [c] CSV   [b] both   [Enter] skip :

  Press Enter to skip, or pick a format. If you export, it then asks WHERE
  to save - type a full path (or a folder), for example
        C:\QC\table_compare.txt
  and only that file is written. (TXT = the full report; CSV = just the
  differences, for Excel.)

  It then asks "Compare another pair? (y/N)" so you can keep going.
  Works with ANY two RTF files anywhere on the computer.

  Prefer clicking files in a dialog instead of pasting paths?
        Double-click  2b-Compare-Using-File-Picker.bat  instead.

------------------------------------------------------------------------
 IF YOUR COMPANY BLOCKS .BAT FILES  (no admin needed - always works)
------------------------------------------------------------------------
  Some locked-down PCs won't run .bat files at all. In that case, drive
  the tool from R directly - R is already installed and allowed:

     1. Open R (Start menu -> "R x.x.x", or RStudio if you have it).
     2. First time only, install the packages - paste this one line
        (use FORWARD slashes "/", and your real folder location):

           source("C:/Users/YOU/Desktop/rtf-comparison-tool/install_packages.R")

     3. To compare, paste this one line (again, forward slashes):

           source("C:/Users/YOU/Desktop/rtf-comparison-tool/run_compare_paths.R")

        ...then paste the two file paths at the prompts (here you can use
        normal backslash paths). It saves the same .txt and .csv reports.

------------------------------------------------------------------------
 IF SOMETHING GOES WRONG
------------------------------------------------------------------------
  "Could not find R"  -> install R from https://cran.r-project.org , then
        redo Step 1.
  A launcher does nothing / is blocked  -> right-click it -> Properties ->
        tick "Unblock" -> OK -> double-click again. (No admin needed.)
  "...library ... is not writable" / "unable to install packages"
        -> handled for you: the installer falls back to your personal library
        (no admin needed). Just run 1-Install-Packages.bat again.
  "...packages failed to install"  -> check internet and run Step 1 again
        (it is safe to run repeatedly).
  Keep the folder intact - the launchers expect the other files to stay
  in the folder above them.

------------------------------------------------------------------------
 OPTIONAL EXTRAS  (in the "windows" folder)
------------------------------------------------------------------------
  2b-Compare-Using-File-Picker.bat  Pick files in a dialog instead of paths.
  3-Run-Tests.bat                   Built-in test suite ("119 passed").
  4-Generate-Test-Data.bat          Creates sample RTF files to practice on.

  For full details, command-line use, and options, see README.md.
